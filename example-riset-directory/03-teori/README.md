# 03-teori

Landasan teori dan kajian konseptual yang mendasari penelitian — dasar ilmiah untuk mendukung Tinjauan Pustaka dan Metodologi.

## Isi yang Diharapkan

- Konsep framework CSS: pendekatan utility-first (Tailwind) vs component-based (Bootstrap)
- Mekanisme optimasi bundle CSS: JIT Compiler (Tailwind) dan PurgeCSS (Bootstrap)
- Core Web Vitals: definisi FCP dan LCP, standar Google, dampak pada UX
- Critical Rendering Path dan pengaruh ukuran CSS terhadap FCP/LCP
- Lighthouse CLI: arsitektur pengukuran, throttling, dan interpretasi skor
