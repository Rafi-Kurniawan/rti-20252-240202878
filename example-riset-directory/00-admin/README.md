# 00-admin

Berkas administratif penelitian: jadwal pelaksanaan, log progres, korespondensi dengan dosen pembimbing, dan catatan administratif lainnya yang tidak masuk ke kategori ilmiah/teknis.

## Isi yang Diharapkan

- Jadwal bimbingan & catatan rapat dengan dosen pembimbing
- Log kronologis pelaksanaan setiap tahap penelitian
- Korespondensi (email, surat pengantar, dsb.)
- Dokumen administratif lain (timeline, checklist submission jurnal)
